The Reading Room is an RSS, Atom and JSON Feed reader. It needs no account: open it and it starts with sample feeds that refresh automatically.

Mac: Window > The Reading Room (Cmd-1) or the Dock icon brings the main window back.

Optional features and what they contact (nothing goes to the developer):
- Conversations (sidebar), Neighborhood tab: works with no account. It arranges posts from feeds the user follows as a social feed and finds links between them. It reads each followed site's home page for its icon and Mastodon/Bluesky links.
- Conversations, Search: words typed go to Bluesky and the user's own Mastodon server through accounts they connected; with no account, only their feeds are searched.
- Person pages: read public home, blogroll and Likes pages of sites the user follows. "Bring your people over" reads who the user follows on their own Mastodon/Bluesky account.
- Mastodon and Bluesky: only after the user connects their own account (Mastodon OAuth on their server, or a Bluesky app password). Shows posts from people they follow; reply, hide, block or report spam.
- Notes, Repost and Weeknotes: only if the user connects their own WordPress site with an Application Password. Posts go to that site (Weeknotes as a post or draft), then optional copies to Mastodon/Bluesky. "Then open X with a copy" opens x.com/intent/post with the text filled in; the app has no X API access.
- Like: kept privately in the app, or with the user's WordPress site connected, added to a Likes page there with a Webmention sent from the device.
- You tab: reads comments on the user's own WordPress site through its REST API.
- Reactions: like and reply counts for a blog post are looked up at webmention.io, a public service many blogs use (the post's address is sent).
- Email (sidebar, optional): the user connects one mailbox of their own (IONOS, Gmail, iCloud Mail, Fastmail, Yahoo, other IMAP/SMTP; on the Mac also Proton Mail Bridge on 127.0.0.1). The app talks straight to that mail server over IMAP/SMTP; the sign-in is kept in the Keychain; dns.google is asked which provider handles the domain's mail.
- The app registers the readingroom:// and feed:// URL schemes; nothing is added without pressing Follow.
- Books: standardebooks.org, LibriVox/archive.org. Help Wanted: job-board RSS and Google News RSS. Discover: Google News RSS, Marginalia Search. Weather: Open-Meteo, if the user types a town.
- Write back: opens the writer's own reply links (email, comments, Mastodon or Bluesky).
- Settings, Help and feedback: Send feedback opens a GitHub issue form in the browser; Rate uses Apple's standard review prompt.
- Newsletters (Add a feed > Read newsletters here): only when the user asks for an address. Made by kill-the-newsletter.com.
- Rules & alerts: local notifications only. Translate: Google Translate.

- Videos (optional): asks YouTube's public oEmbed endpoint who made videos found in posts; if a channel's feed fails, reads its public Videos page. Save for offline downloads podcast episodes and video files from feeds (never YouTube/Vimeo). Comment on YouTube copies the text and opens the video; nothing is posted to YouTube.

- My Day (sidebar, optional; Settings > Experimental): Calendar and Reminders are read on the device through EventKit after the system asks (Allow button on My Day). The app writes only what the user adds there: an event, a reminder, and a Reminders list named "The Reading Room". Day One entries open through Day One's own dayone:// link. Markets: stocks use the user's own free Finnhub key; coins use CoinGecko (coin ids only).

Sync between devices is optional and uses a folder in the user's own iCloud Drive.

No login is needed to review the app. Conversations opens on the Neighborhood, which works without any account; the first visit suggests a few writers to follow. Email, Mastodon, Bluesky and WordPress are optional connections to the user's own accounts.
