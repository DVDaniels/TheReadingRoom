The Reading Room is an RSS, Atom and JSON Feed reader. It needs no account: open it and it starts with sample feeds that refresh automatically.

Mac: Window > The Reading Room (Cmd-1) or the Dock icon brings the main window back.

Optional features and what they contact (nothing goes to the developer):
- Conversations (sidebar), Neighborhood tab: works with no account. It arranges posts from feeds the user follows as a social feed and finds links between them. It reads each followed site's home page for its icon and Mastodon/Bluesky links.
- Conversations, Search: words the user types are sent to Bluesky (post search) and to the user's own Mastodon server, through the accounts the user connected; the blogs part searches the user's feeds on the device. With no account, only the feeds are searched.
- Person pages and "Liked by": read the public home, blogroll and Likes/Bookmarks pages of sites the user follows, and a post's comments from that site. "Bring your people over" reads who the user follows on their own Mastodon/Bluesky account.
- Mastodon and Bluesky (Conversations): only after the user connects their own Mastodon account (OAuth on their own server) or Bluesky account (an app password). Shows posts and replies from people they follow and lets them reply. Accounts can be hidden, blocked, or reported as spam.
- Notes and Repost: only if the user connects their own WordPress site with an Application Password. Posts go to that site, then optional copies to Mastodon/Bluesky. "Then open X with a copy" opens x.com/intent/post with the text filled in; the app has no X API access.
- Like (Conversations): without a site connected, a like is kept privately in the app. With the user's WordPress site connected, the liked post is added to a Likes page on that site and a standard Webmention is sent from the device to the liked post's site. Likes on Mastodon/Bluesky go to the user's own account there.
- You tab: reads comments on the user's own WordPress site through its REST API.
- Reactions: like and reply counts for a blog post are looked up at webmention.io, a public service many blogs use (the post's address is sent).
- Email (sidebar, optional): the user connects one mailbox of their own (IONOS, Gmail, iCloud Mail, Fastmail, Yahoo, other IMAP/SMTP; on the Mac also Proton Mail Bridge on 127.0.0.1). The app talks straight to that mail server over IMAP and SMTP to show the newest 100 emails, send replies and new emails, and move deleted emails to the mailbox's Trash. The sign-in is kept in the Keychain. It asks dns.google which provider receives mail for the domain, to warn about a mismatch. Nothing passes through the developer.
- Open in The Reading Room links: the app registers the readingroom:// and feed:// URL schemes. Nothing is added without pressing Follow. Try: readingroom://subscribe?url=https://daringfireball.net/feeds/main
- Books: standardebooks.org; audiobooks: LibriVox/archive.org. Help Wanted: public job-board RSS feeds and Google News RSS. Discover: Google News RSS and Marginalia Search. Weather: Open-Meteo, only if the user types a town.
- Write back: opens the writer's own reply links (email, comments, Mastodon or Bluesky).
- Settings, Help and feedback: Send feedback opens a GitHub issue form in the browser; Rate uses Apple's standard review prompt.
- Newsletters (Add a feed > Read newsletters here): only when the user asks for an address. Made by kill-the-newsletter.com.
- Rules & alerts: local notifications only. Translate: Google Translate in the app's web window.

Sync between devices is optional and uses a folder in the user's own iCloud Drive.

No login is needed to review the app. Conversations opens on the Neighborhood, which works without any account; the first visit suggests a few writers to follow. Email, Mastodon, Bluesky and WordPress are optional connections to the user's own accounts.
